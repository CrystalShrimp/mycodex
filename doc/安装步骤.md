# MyCodex 安装部署指南（Windows）

> 从零到可用共 4 步，全部双击脚本完成；任何步骤失败都可**直接重跑**，会从上次完成的进度续跑。

## 前置条件

- Windows 10/11，可联网
- 其余（Node.js / Python / Codex CLI）缺失时均自动安装，无需提前准备

## 第一步：环境安装（约 10 分钟）

进入 `launcher_windows` 文件夹，双击 **`MyCodex-Setup.bat`**，按提示确认（直接回车 = 是）：

| 自动完成项 | 说明 |
|---|---|
| Node.js 20+ | 缺失时从国内镜像下载并静默安装 |
| Python 独立环境 `.venv` | 自动安装 uv 并执行 uv sync |
| 飞书自动化依赖 | npm install + Chromium 内核（约 120MB，首次较慢） |
| `.env` 配置文件 | 从模板创建 |
| Codex CLI | npm 全局安装（国内镜像）；执行任务依赖本机 ChatGPT 登录态（`codex login`），无需 API Key |
| 开机自启（可选） | 最后询问，Y = 加入启动项 |

✅ 完成标志：`一键自检安装完成！`

## 第二步：消息平台配置（飞书 / 企业微信，约 5-8 分钟）

第一步向导结束时会自动进入「MyCodex 配置中心」菜单（重跑 `launcher_windows\MyCodex-Setup.bat` 可随时再次进入；macOS 双击 `launcher_macos/MyCodex-Setup.command`）：

- **`1. 配置飞书 - 个人用`**：全自动配置，应用可用范围保持仅限创建者（个人私用极速模式）；
- **`2. 配置飞书 - 公用`**：全自动配置，应用可用范围改为企业全员，默认 `ALLOWED_USERS` 留空（全员开放），并可在配置完成后一键拉取特定群聊的所有用户 ID 批量导入为白名单；
- **`3. 飞书群成员一键导入白名单`**：随时选择或输入群 ID，一键将目标群全体成员同步至 `.env` 白名单；
- **`4. 配置企业微信`**：按提示在企业微信管理后台创建智能机器人并填写 BotID / Secret；
- **`5. 完整配置`**：飞书公用 + 企业微信双通道同时在线；
- **`0. 退出`**：完成并显示启动说明（含开机自启询问）。

✅ 完成标志：菜单选 0 退出，显示 `[SUCCESS] MyCodex 安装与配置完成！`。

## 第三步：启动服务

双击 **`launcher_windows\MyCodex.bat`**（自动清理残留进程后启动）：

- 验证：浏览器打开 `http://127.0.0.1:8090/health`，返回 `"status":"ok"` 即正常
- 右下角出现托盘图标（首次启动约 30 秒），右键可查看状态 / 日志 / 退出
- 之后重启（改代码或配置后）：双击 `launcher_windows\MyCodex-Restart.bat`

## 第四步：添加使用者白名单

1. 用飞书给机器人发任意消息
2. 收到「权限拦截提醒」→ 里面包含使用者的 Open ID（若直接回复则无需此步）
3. 把 Open ID 填入 `.env` 的 `ALLOWED_USERS=`（多人用逗号分隔；**留空 = 允许所有人**）
4. 双击 `launcher_windows\MyCodex-Restart.bat` 生效

## 验证与开始使用

- 发一条消息（如“你好”）→ 机器人流式回复 ✅
- **开箱即用与全局配置**：
  - 首次使用自动继承全局默认配置（模型 `gpt-5.6-terra` / 推理强度 `medium` / 审批模式 `m`），无需三道卡片阻塞即可直接对话；
  - 详见 `setup.md`，三大要素全局生效，切换目录或新建会话无需重新配置；
  - 随时可通过 `/model`、`/effort`、`/mode` 指令或卡片调整配置。
- `/status` 查看运行状态；`/help` 查看全部指令

## 常见问题

| 现象 | 处理 |
|---|---|
| macOS 双击提示没有权限 | 在终端执行 `chmod +x launcher_macos/*.command scripts/*.sh`；若提示隔离警告可执行 `xattr -dr com.apple.quarantine launcher_macos/` |
| 窗口闪退或中文乱码 | 使用最新版脚本（旧版编码问题已修复）；失败时窗口会停住并显示原因，按提示处理 |
| Chromium 下载慢 / 失败 | 最新向导已默认集成 npmmirror 国内镜像加速与已安装秒级检测；若偶发中断，重跑向导即可自动续传 |
| 收到「权限拦截提醒」 | 正常引导流程：把消息里的 Open ID 加入 `.env` 的 `ALLOWED_USERS` |
| 服务 60 秒未上线 | 查看 `logs\mycodex.log`，然后双击 `launcher_windows\MyCodex-Restart.bat`（macOS 运行 `launcher_macos/MyCodex.command`） |
| Codex 未登录 | 终端执行 `codex login`，完成浏览器 ChatGPT 授权后重启 |
| 机器人不回消息 | 依次检查：托盘是否在 → `/health` 是否 ok → 是否换了飞书应用（换过则需重新执行第二步） |
